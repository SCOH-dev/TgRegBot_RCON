TgRegBot_Rcon

Бот для регистрации в тг для приватного сервера
С базой данный sqlite3

После регистрации вашего аккаунта, откройте файл Базы Данных и измените значение Admins на 1

Для работы бота, создайте ".env"
```
# Токен телеграм бота, брать от BotFather
TG_TOKEN=748202506:AAE8mTR1hs9RQgvFkw4DEN_3qyzmmpHWY
# ip_address вашего сервера, если бот установлен с сервером на одном сервере, то 127.0.0.1
RCON_HOST="node4.su"
# Порт вашего rcon, можно узнать в файле server.properties
RCON_PORT=25614
# Пароль от вашего rcon, можно узнать в файле server.properties
RCON_PASSWORD="пароль"
```
